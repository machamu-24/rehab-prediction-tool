# 架空患者モデル

文献照合画面の右側、照合結果欄の下にある「入力例：架空患者モデル（補足）」を開くと、4症例 × 3評価時点の12パターンを選択できます。初期表示では折りたたんでいます。すべて動作確認・比較用に作成した架空の値で、実患者データや回復の標準値ではありません。

症例と評価時点を選び、「このモデルを入力」を押すとフォームへ反映します。読み込み後の数値は編集できます。「保存せず照合」で結果を確認し、必要に応じて「照合して履歴に保存」を使用してください。

各モデルにはMMSE、CBA、FMA下肢、Brunnstrom下肢、TCT、膝伸展筋力、歩行状態なども設定しています。各症例の入院時情報は経過評価でも維持し、現在の評価値とは別に入力されます。歩行速度・TUGが未測定の設定では空欄とし、未設定のその他の評価も空欄のままにします。

発症から入院までは30日とし、評価時点は発症後30日・51日・60日です。入棟3週間後FIMは3週以降のモデルだけに、ΔBBS・ΔFIMは1ヶ月後のモデルだけに設定しています。変化量は「1ヶ月後 − 入院時」です。

症例IDは評価時点を変えても共通です。評価日は1ヶ月後の評価を読み込み当日に合わせ、入院時を30日前、3週後を9日前に設定します。履歴へ保存すると時系列で確認できます。

通常の時間軸では評価時点だけを設定し、退院日などの予測対象時点は決めていません。Koyamaモデル用には、3週後・1ヶ月後の再評価値と発症後120日の予測対象日を設定します。入院時モデルには将来の実測値を含めません。選択した文献の対象条件や不足項目・時期によって、判定対象外や参考結果になる場合があります。

定義ファイル：`shared/patientModels.ts`

SAMPLE-Aは入院時FIM合計が55点を超えるため、低FIM患者を対象とするIkeueモデルの対象条件外です。また経過例を発症後120日へKoyamaモデルで外挿すると126点を超えるため、通常の予測値表示が停止されます。対象条件や得点範囲による除外も確認できる構成です。
