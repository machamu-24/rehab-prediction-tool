# 文献の評価時期と集計（2026-11-06更新）

時間軸は発症日を0日とした「日数」で入力します。

支持・困難の集計には、評価時点・アウトカム測定時点の日数差による制限を設けません。平均値・中央値・概算、時点不明、時間軸未登録でも、ほかの集計条件を満たす文献を集計します。時間軸の入力と照合範囲の設定は任意です。

## 管理者の設定

1. 「文献ルール管理」で対象文献を編集し、「時間軸」タブを開きます。
2. 評価時点と予測対象時点それぞれについて、「照合する時期の範囲を設定する」を選びます。
3. 発症後の開始日・終了日と、範囲の根拠・設定理由を入力します。両端の日も照合対象です。
4. プレビューで範囲を確認してから更新します。

例えば、評価時点23〜37日・予測対象時点76〜104日と設定すると、評価30日・予測90日は範囲内です。この数字は操作説明用の例であり、標準設定や医学的な適用基準ではありません。

文献が示す対象期間と、管理者が確認用に設定した範囲を、根拠欄で区別してください。「発症14日未満」などの研究対象条件は「適用条件」で別途保持します。適用条件は引き続き判定します。

## 集計と表示

- 明確な時点が一致すれば「時点一致」、設定された範囲内なら「設定範囲内」と記録します。これらは時間軸の照合結果であり、集計の必須条件ではありません。
- 平均値・中央値・概算を含む場合、日数が異なる場合、確認用の範囲外の場合、時点が不明・未登録の場合は「評価時期の確認」を表示します。平均値・中央値は、範囲内でも確認ラベルを表示します。
- ほとんどの文献が平均値で登録されていても、すべての集計可能な文献を支持・困難に振り分けます。確認ラベルは注意情報であり、確認操作や根拠の追加入力は要求しません。
- サマリーには「支持・困難の集計対象：○件／うち評価時期の確認：○件」を表示します。確認件数は実際に集計した二値判定の内数です。
- 将来予測と同時点判別の種類が異なる文献は対象外です。文献の集計除外設定、適用条件、入力不足、未対応モデル、不正な設定は従来どおり判定します。数値予測・記述型出力は支持・困難に加えません。
- 各文献に評価時点・アウトカム測定時点・原著表記を表示し、詳細に時期の確認理由を表示します。結果保存時には時間軸と照合結果をスナップショットに保持します。

文献の日数・範囲は推測で補完しません。既存の範囲設定も保持します。新しい集計は計算版`local-2026.11.06-v1`で記録し、過去の履歴や保存済みの集計区分は変更しません。

## 既存の月単位データ

月単位の文献・照合条件も読み込めます。1ヶ月＝30日の目安で日数へ換算し、月単位の明確な値は「概算」に変更します。文献の原著表記と根拠は保持し、文献には換算前の月数も記録します。読み込みだけではDBを一括更新せず、文献の更新時に日数の時間軸を保存します。

新しく月単位の文献を登録する場合も日数に換算し、原著表記・換算方法・概算であることを記録してください。

範囲設定は文献の適用性能を検証したことを意味しません。支持件数は登録ルールの傾向であり、患者個人の予測確率ではありません。
